# Image Document Use Cases in SchoolPalm

The Image Document module in SchoolPalm will allow schools to generate, process, optimize, and manipulate image-based documents. It will support school branding, communication, reporting, digital certificates, social media content, and visual assets.

## 1. Student Identification Cards

Generate professional student ID cards dynamically.

- Student photo placement
- School logo and branding
- Student details
- Barcode or QR code generation
- Academic year information
- Automatic resizing for printing

Example:  
`Document::image() ->studentCard() ->photo() ->size(850,540)`

- WEBP - optimized web images

- BMP - legacy support
